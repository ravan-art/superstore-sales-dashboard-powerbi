# 📊 Superstore Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** designed to analyze sales performance, profitability, product categories, sub-categories, customer payment modes, and time-based sales trends.

The project uses **Power Query for data cleaning and transformation, DAX for KPI calculations, and data modeling for analytical reporting**.

---

## 🎯 Business Objectives

The main objectives of this project were to:

* Analyze overall sales performance
* Monitor profitability
* Identify high-performing product categories
* Analyze sub-category performance
* Understand payment mode distribution
* Analyze sales trends over time
* Identify patterns that can support business planning
